# Larporithm

**You are the algorithm.**

Larporithm is a small Godot game about recommendation systems. Instead of being the person watching videos, you play as the algorithm trying to keep a user engaged.

## What it does

The player types video titles into a search bar. The game checks what kind of video the title sounds like, compares it to a hidden user profile, and changes the timer based on how good the recommendation is.

Good recommendations keep the user watching. Bad recommendations make the user lose interest.

## Why we made it

We wanted to show how recommendation algorithms can shape what people watch. The game makes that idea interactive by letting the player control the recommendations directly.

## Built with

- Godot
- GDScript
- Gemini API
- Python
- JSON

## How to run

1. Download or clone this repo.
2. Open the folder in Godot.
3. Open `project.godot`.
4. Press Play.

## Project status

This is a hackathon project and still a work in progress. The main pieces are built, including the start menu, search bar, timer, emotion system, analytics panel, and AI title scoring. We are still polishing the full gameplay loop.
